# Роадмап

Цель — DAW с упором в низкий уровень: инструменты и эффекты собираются из примитивов, всё звучит с точностью до сэмпла.

## Сделано

- Формат проекта v1: строковые id типов, таблица медиа. Чтение v0 сохранено, на всё это есть тесты.
- Автосохранение, файлы `.wnodes`, ссылки-шаринг, «вернуть предыдущий».
- Редизайн по макету CUSTOMITY: тема, категории, UI-кит, иконки.
- Медиатека (IndexedDB), Sampler, Player с сохранением файла, Recorder в медиатеку.
- MIDI: Midi In (моно), Midi CC с Learn.
- Expression: безопасный компилятор формул в AudioWorklet.
- Блоки: Group, Group Input/Output, сворачивание и разворачивание, вложенность, библиотека «Мои блоки».
- Модуляция: LFO, ADSR, Random, Counter.
- Компиляция блоков (v1): блок из Math, Expression, Memory, Slider, Toggle, LFO, ADSR, Counter и Random работает как один AudioWorklet, петли — с задержкой в 1 сэмпл.
- Convolver и Drums с файлами из медиатеки.
- Undo/redo: откат разницей между снимками, без пересоздания неизменившихся нод.
- Исправления: утечки Keyboard и микрофона, частоты нот, `signify`, состояние worklet'ов из пула, горячие клавиши при вводе в полях.

## Дальше, по порядку

1. **Разделить модель, движок и вид.** Сейчас звук живёт внутри React-компонентов: WebAudio-узлы — поля нод, связи создаются при монтировании портов. Нужно три слоя: модель (граф как данные), движок (аудио-объекты, `AudioContext` передаётся параметром) и вид (React). После этого:
   - экспорт в WAV через `OfflineAudioContext` быстрее реального времени;
   - блоки без скрытого DOM;
   - undo/redo на снимках модели.
2. **Компиляция блоков, дальше.** Первая версия есть (см. ARCHITECTURE). Осталось:
   - Smoothing, Timer, Impulse, Sequencer и вложенные блоки;
   - нативные ноды (Biquad, Convolver) как границы компилируемых «островов» вместо отказа целиком;
   - не считать внутренние ноды, пока блок скомпилирован;
   - сохранять состояние (Memory, фазу LFO) при перекомпиляции.
3. **MIDI и полифония:**
   - порты событий (ноты и CC с метками времени, доставка в worklet по времени контекста);
   - нода Poly, размножающая блок-голос на N голосов;
   - сустейн (CC 64);
   - MIDI Out;
   - MIDI-файл как источник нот.
4. **Транспорт и таймлайн:**
   - музыкальное время (такты, доли, тики), карта темпа, луп;
   - треки с клипами: ноты, аудио, автоматизация. Каждый трек — граф или блок-инструмент;
   - piano roll.
5. **Связанные блоки.** Правка определения обновляет все копии. Сохранение в «Мои блоки» уже есть.
6. **Ноды из макета CUSTOMITY:**
   - Curve (редактируемая кривая);
   - утилиты: Remap, Clamp (сейчас — через Math);
   - маршрутизация: Teleport (беспроводная связь по ID), Dummy (перегиб провода), порты на несколько связей («connection combiners»);
   - эффекты: Reverb, Chorus, Flanger, Phaser, Pitch / Frequency Shift, Stereo Enhancer;
   - анализ: Spectrogram, EQ.

## Известные проблемы

- **Предупреждение React в режиме разработки** «Cannot update a component while rendering a different component». Возникает при рендере `rsp.td` (Keyboard, Drums) и списка MIDI-устройств. Было и до этой работы, в продакшене не видно, на работу не влияет.
- **Горячая перезагрузка Vite** иногда роняет страницу посреди работы: новые модули создают новые контексты. Обычная перезагрузка страницы помогает. Счётчик процессоров в `defineWorklet` сбрасывается при HMR, что тоже даёт конфликты имён.
- **MIDI:**
  - значения выставляются из колбэка `onmidimessage` без планирования по меткам времени;
  - в Safari Web MIDI нет.
- **Expression:**
  - каждая новая применённая формула регистрирует модуль worklet'а, и он живёт до перезагрузки;
  - при смене формулы `y1` сбрасывается, кроссфейда нет.
- **Блоки:**
  - внутренний редактор каждого блока смонтирован всегда: на сотнях блоков это лишняя память;
  - копии блока независимы;
  - перехват Ctrl+G в Chrome на macOS отменяет «найти далее» только на странице редактора.
  - скомпилированный блок не экономит CPU: внутренние ноды продолжают работать; при смене структуры состояние сбрасывается, а модуль worklet'а остаётся до перезагрузки.
- **Автосохранение** одно на браузер: пишет только видимая вкладка, чужое состояние уходит в «previous». Две видимые вкладки рядом всё ещё спорят за один слот.
- **Ссылка-шаринг** с большим файлом не включает медиа. Кнопка честно об этом пишет, но лучше делиться файлом `.wnodes`.
