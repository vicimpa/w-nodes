# WebAudio Nodes

[English](README.en.md) · **[Открыть в браузере →](https://vicimpa.github.io/w-nodes/)**

Модульный синтезатор в браузере. Звук собирается из нод — генераторов, фильтров, секвенсоров, сэмплеров, математики — и проводов между ними. Всё работает на Web Audio API: ноды — это настоящие `AudioNode` и `AudioWorklet`, управляющие сигналы идут на частоте дискретизации, а не через JS-таймеры.

![Редактор](screen/editor.jpg)

## Возможности

- **Нодовый редактор**: перетаскивание, выделение рамкой, зум, копирование между вкладками и проектами.
- **30+ нод**: генераторы, эффекты, анализаторы, секвенсор и барабаны, математика, MIDI, сэмплер, запись.
- **Блоки** — свои ноды из других нод: выделил, нажал <kbd>Ctrl</kbd>+<kbd>G</kbd>, получил блок с портами. Блоки вкладываются друг в друга.
- **Expression** — формула на каждый сэмпл: `sin(TAU * a * t) * b + y1 * 0.5`. Компилируется в AudioWorklet через собственный безопасный парсер.
- **Медиатека**: аудиофайлы хранятся в браузере и вшиваются в проект. Sampler играет их с точностью до сэмпла, Recorder пишет звук прямо в медиатеку.
- **MIDI**: MIDI-клавиатуры и контроллеры через Web MIDI.
- **Проекты не теряются**: автосохранение, файлы `.wnodes`, ссылка на проект одной строкой, «вернуть предыдущий».

## Быстрый старт

```bash
git clone https://github.com/vicimpa/w-nodes.git
cd w-nodes
npm install
npm run dev      # http://localhost:5173
```

Остальные команды:

```bash
npm test         # vitest: формат проектов, демо, медиа, MIDI, компилятор формул
npm run build    # tsc + сборка в dist/
```

## Как пользоваться

1. Добавьте ноду из меню слева: клик ставит её в центр экрана, перетаскивание — в нужное место.
2. Тяните провод от порта к порту. Провод красится в цвет ноды-источника.
3. Включите звук: нода **Destination** — это колонки.
4. Откройте любое демо в панели справа: `car`, `club`, `piano`, `lastv`… В заметках внутри демо написано, что нажимать. `car` — V8 до 10 900 об/мин с автоматической коробкой на 5 передач, турбиной и приборной панелью, звук собран по схеме `car-classic`: пробел заводит, W — газ, S — тормоз; прежняя версия лежит в `car-classic`. Новые ноды показывают `orbit` (звук кружит вокруг головы через Panner, нужны наушники), `bells` (генеративные FM-колокольчики на Random и Expression), `arp` (арпеджио на Counter и Constant), `theremin` (терменвокс на Bi Slider) и `midi` (синтезатор для MIDI-клавиатуры).

### Порты

| Вид | Что передаёт |
|---|---|
| ◯ кольцо | **аудио** (стерео): звук между генераторами и эффектами |
| ● точка | **сигнал** (моно, на частоте звука): значения параметров, модуляция, триггеры |

Их можно соединять между собой: аудио в параметр — это модуляция, сигнал в аудиовход — это постоянное смещение. Цвет порта показывает категорию ноды.

Почти у каждого параметра (строка со слайдером или числом) есть свой сигнальный вход. Когда он подключён, ручка становится индикатором и показывает пришедшее значение.

| <kbd>Shift</kbd> + копирование/вставка | Без проводов к нодам вне выделения |

### Проекты

- **Автосохранение**: проект и положение карты сохраняются в браузере каждые пару секунд.
- **New / Open / Save**: новый проект, открыть или сохранить файл `.wnodes`. В файл вшиваются все используемые медиа.
- **Share**: копирует ссылку `…/#p=…`, внутри которой лежит весь проект. Медиа попадают в ссылку, если они небольшие (до 256 КБ). Если не влезли, кнопка так и скажет; тогда делитесь файлом.
- **Restore previous**: открытие демо, ссылки или файла не затирает работу. Предыдущий проект можно вернуть одной кнопкой.
- **Arrange nodes**: расставляет выделенные ноды (или все) слева направо по ходу сигнала, без перекрытий; отменяется через <kbd>Ctrl</kbd>+<kbd>Z</kbd>.
- Перетащите на холст файл проекта или аудио: проект вставится, аудио станет нодой Sampler.

Старые строки проектов (из буфера, из папки с примерами) открываются как раньше.

### Блоки

Выделите ноды и нажмите <kbd>Ctrl</kbd>+<kbd>G</kbd>. Провода, выходившие из выделения, станут портами блока. **Open block** открывает его внутренности. Там из меню можно добавлять ноды **Group Input** и **Group Output**: это новые порты блока, а их имена — подписи портов. Блок копируется, сохраняется и вкладывается в другие блоки, как обычная нода. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> распаковывает его обратно.

Переключатель **Compiled** собирает блок в один AudioWorklet, если внутри только Math, Expression, Memory, Slider, Toggle, LFO, ADSR, Counter, Random и Group Input/Output. Обратная связь внутри такого блока запаздывает на 1 сэмпл, а не на 128. Если блок собрать нельзя, он звучит как обычно, а причина видна на нём самом.

### Expression

Формула вычисляется для каждого сэмпла. Её текст хранится в проекте и при открытии чужой ссылки **не исполняется как JavaScript**: его разбирает собственный парсер, который пропускает только описанное ниже.

- Переменные: входы `a b c d`, время `t` (секунды), частота дискретизации `sr`, предыдущий выходной сэмпл `y1` (обратная связь в 1 сэмпл).
- Константы: `PI E TAU`.
- Операторы: `+ - * / % **`, сравнения (дают 0/1), `&& || !`, `?:`.
- Функции: `sin cos tan asin acos atan atan2 sinh cosh tanh exp log log2 log10 pow sqrt abs sign floor ceil round trunc min max clamp mix fract mod noise`.

### Медиа, Sampler, Recorder

- **Sampler**: запуск по фронту сигнала `Trigger` с точностью до сэмпла, 8 голосов, скорость воспроизведения (отрицательная — задом наперёд), начало и конец, луп пока держится триггер.
- **Player**: длинные файлы со стандартными кнопками.
- **Recorder**: записывает входящий звук. Запись появляется в медиатеке, её можно сразу подать в Sampler или скачать.
- Файлы лежат в IndexedDB браузера и никуда не отправляются.

### MIDI

**Midi In** выдаёт `note`, `freq`, `gate`, `velocity`, `bend` (моно, приоритет последней ноты). **Midi CC** выдаёт значение контроллера 0…1, а кнопка **Learn** ловит номер CC с первого движения ручки. Нужен браузер с Web MIDI: Chrome или Edge; в Firefox — после разрешения для сайта.

## Ноды

| Категория | Ноды |
|---|---|
| **Input / Output** | Oscillator, Sampler, Player, Input (микрофон), Midi In, Recorder, Destination |
| **Controls** | Slider, Toggle, Bi Slider (XY-пад), Keyboard (клавиши компьютера), Midi CC |
| **Time** | Timer, Delay, Smoothing (плавный переход с кривой), Impulse, LFO, ADSR (огибающая), Project (транспорт: run, time) |
| **Sequencing & Routing** | Sequencer (16 шагов), Drums, Channel Splitter (split / merge / swap) |
| **Effects** | Gain, Biquad Filter, Convolver (реверб), Dynamics Compressor, Panner (3D, вид сверху с конусом и кривой затухания), Stereo Panner |
| **Math & Memory** | Math (≈70 операций и функций), Expression, Constant (π, e, φ, частота дискретизации… или своё число), Memory (sample & hold), Random, Counter |
| **Monitors** | Analyzer (спектр/волна), Oscilloscope (XY), Show Value, Turner (самописец сигнала) |
| **Blocks** | Group, Group Input, Group Output |
